## OpenUsage

UsagePeek is a Windows-oriented adaptation and independent C# reimplementation
based on the interface, usage-metering concepts, pace projection, provider
abstraction, and local-usage aggregation ideas from
[OpenUsage](https://github.com/robinebers/openusage).
The Antigravity conversation-accounting field layout follows the format
documented by FelixIsaac and the OpenUsage contributors in
[OpenUsage #1120](https://github.com/robinebers/openusage/issues/1120).

UsagePeek is an independent community project. It is not an official OpenUsage
release and does not use the OpenUsage name or logo as its own branding.

## Desktop pet artwork

The whale-maid desktop pet artwork embedded as
`assets/pet-whale-maid-curled.png` was supplied for use in UsagePeek. Artwork
credit: **ZipZipPipe**.

The Phoebe Chibi desktop pet artwork embedded as
`assets/pet-phoebe-chibi.png` was supplied by a tester for use in UsagePeek.

Both artworks are separate from the MIT-licensed source code and are not
relicensed under the repository's MIT License. Copyright and other artwork
rights remain with their respective rights holders.

The ChatGPT-girl desktop pet artwork embedded as
`assets/pet-chatgpt-girl.png` was generated for UsagePeek with the built-in
imagegen tool using a user-supplied character reference. Its generation
prompt is saved in `assets/pet-chatgpt-girl.prompt.txt`.

The Claude-girl and milk-frog desktop pet artworks embedded as
`assets/pet-claude-girl.png` and `assets/pet-milk-frog.png` were generated for
UsagePeek with the built-in imagegen tool using user-supplied visual references.
Their generation prompts are saved alongside the PNG files as
`assets/pet-claude-girl.prompt.txt` and `assets/pet-milk-frog.prompt.txt`.

The five early frame-animation studies in `assets/animations/` were generated with
the built-in imagegen tool using the existing character artwork as references.
Their prompt set and packing details are recorded in `assets/animations/PROMPTS.md`.
The whale-maid and Phoebe character credits and artwork rights above also apply
to their derived animation frames; those frames are not relicensed under MIT.
These studies are kept as design references and are not embedded in the current
executable. The continuous 2D rig uses the original character PNGs as textures;
their existing artwork credits and rights continue to apply.
